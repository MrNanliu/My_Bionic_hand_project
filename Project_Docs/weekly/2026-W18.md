## Blockers / Questions
- **Crucial Finding (Hardware Logic Flaw)**: The testing this week shows that the performance drop may not due to a Python software issue. The Arduino firmware currently uses a static baseline calibration during the first 3 seconds combined with an `abs()` function. When physical electrode drift occurs over time, this logic incorrectly flips negative baseline drifts into positive "false peaks," confusing the Random Forest model.
