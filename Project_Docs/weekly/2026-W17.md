## Blockers / Questions
- **Performance Collapse in Time-based Splitting**: A severe drop in accuracy (from ~86% to ~14%) was observed when using chronological splitting. This highlights significant signal non-stationarity and baseline drift, which is a common pitfall in sEMG machine learning as cited in literature (e.g., Nature Machine Intelligence, 2021).
- **Hardware Limitations (Dry Electrode Challenges)**: Quantitative analysis confirms that while the copper electrode sensor is convenient, it suffers from high sensitivity to motion artifacts and pressure-induced baseline shifts. These hardware characteristics represent the primary bottleneck, making distance-based classifiers like SVM ineffective without advanced dynamic calibration.
